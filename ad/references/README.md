# References and source boundaries

`ui-sources.json` records the inspected gact-tui revision, files, hashes and
recognizable product elements used by this reconstruction. `SOURCE-REUSE.md`
retains the original source/branding notes and `GACT-LICENSE.txt` retains the
upstream MIT notice.

The three `motion-video-*.md` files are the earlier motion skills supplied during
this work. They explain frame-driven animation, renderer setup and sampled review.
They are historical references, not the current product brief. Follow
`../HANDOFF.md` and `../skills/clio-composable-ad/SKILL.md` where their old scene
prescriptions or platform setup differ from this film. In particular, do not call
React hooks inside mapped/conditional code, and do not reuse old CLI commands or
assume a previous concept video's art direction was approved.

The craft references linked in `../ART-DIRECTION.md` inform motion clarity and
product-derived form. Their footage, artwork, copy and soundtrack are not included.
The user-supplied HTML prompt-morph example demonstrated stable text, opening new
line space, staggered insertion and fading highlights after a plugin addition;
the current effect is implemented as frame-driven editable React components.
