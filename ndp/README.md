# NDP scientific sessions

Original HTML exports downloaded without modification from the public [NDP examples](https://clio.iowarp.ai/docs/examples/ndp-science/#download-the-conversations), release tag `ndp-scientific-conversations-2026-10-19` in iowarp/clio-agent. Checksums match the published asset pins. Verify raw bytes against SHA256SUMS with a SHA-256 utility such as PowerShell's Get-FileHash.

- Alta-snowfall-session-maps-v2.html: seasonal and monthly snowfall; the film uses turns 1–2. Turn 3 packages a reproducibility bundle and is omitted.
- Konza-session-maps-v2.html: particle, wind and CO₂ observations. The film uses turns 1–2. The session starts with NDP-acquired data already present, so the film does not manufacture fresh discovery or acquisition. Turn 3's collaborator handoff is outside this cut.

Selected native scenes retain rich views and required artifact bytes. The campaign is authored presentation of recorded activity, not a new scientific run. Source publishers, coverage and sensor qualifications remain in the saved views and transcript. These assets do not independently requalify the scientific conclusions.
