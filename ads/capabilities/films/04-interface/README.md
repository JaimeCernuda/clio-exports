# 4. The answer is an interface.

An answer can be a tool you can use.

**Visible proof:** Changing baseline updates quartiles and deltas; month choices focus the comparison; export retains that view.

**Evidence:** `alta.json; science.json; exports/`. See [campaign source ledger](../../SOURCES.md).

**Presentation limits:** Reconstructed control gestures using archived scientific data; unselected months remain faint chart context.

**Difficult mechanic:** Controls, pointer and linked values must agree while rows collapse smoothly.

## Edit and render

`scene.tsx` is the editable composition; `storyboard.json` is its shot/copy handoff.
From the campaign root, run `node render.mjs interface --draft`, inspect, revise,
then `node render.mjs interface` and `node scripts/review.mjs interface`.
The latest local output is `../../output/04-interface.mp4`.
Review findings belong in [the campaign review history](../../REVIEW.md).
