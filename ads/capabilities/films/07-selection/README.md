# 7. Ask your data.

Ask a question scoped to selected scientific records.

**Visible proof:** The same 12 geographic observations become highlighted rows and a composer reference. A genuine PTC program reads those records and computes the peak before the answer appears.

**Evidence:** `hurricane.json; atlantic-basemap.json; execution/selection-*.json; product/requests/selection-analysis.kernel`. See [campaign source ledger](../../SOURCES.md).

**Presentation limits:** Authored reference gesture using actual NOAA rows and Natural Earth geometry. The read/maximum calculation is retained native execution; public activity labels condense it and do not invent model reasoning.

**Difficult mechanic:** Keep map labels as stable DOM text and preserve the selection through the reference handoff, record read, computation and answer.
