# Composable agent: advertising treatment

The two interface-led versions were rejected. Their failure was editorial: they
put implementation details on screen and held a page layout while changing its
contents. More interface fidelity, additional cards, or a nicer shadow cannot
solve that problem. This treatment supersedes those versions for the social film.

## Idea

**The colored word becomes the capability that changes the agent.**

One visual material travels through the film: a colored word highlight becomes
an add control, then a plugin piece. The viewer follows the object into the build.
The existing instructions stay; each added piece opens space for a new prompt
fragment. Named Skills and MCP contributions dock into their own slots. The close
invites the viewer to make their own combination.

The audience needs to understand customization through composition. It does not
need an explanation of core, filesystems or package internals. More than a dozen
understandable domains establish breadth. One manufacturing build makes additive
composition readable. These are illustrative configurations, not a claim that
those named plugins ship.

## Research and decisions

- [BUCK / Notion: Think It. Make It.](https://buck.co/work/notion-think-it-make-it):
  the creators describe replacing literal interface representation with a
  conceptual foundation and a succinct brand story. Apply that distinction here:
  lead with what the agent can become, not a catalogue of its implementation.
- [Oddfellows / Figma](https://oddfellows.tv/work/figma): its creator breakdown
  treats code as a material that joins typography, color and pattern. Our inference
  is to make a capability and its written instruction the same transforming
  visual object, rather than separate panels connected by explanatory labels.
- [Ordinary Folk / work](https://www.ordinaryfolk.co/work): concept-led product
  films and the original repository motion skills inform the frame-driven scene
  structure, object handoffs and rhythmic contrast. These are craft references;
  no competitor artwork, footage, copy or soundtrack is reused.
- The user-supplied Quests film is a quality and motion reference, not a template.
  It was inspected locally; no footage is included in the CLIO film.
- [BUCK / Google Vids](https://buck.co/work/google-vids): the creator describes a
  script/storyboard-first film extending Google's existing visual language. Our
  application is to retain CLIO's recognizable controls while letting pieces
  move and change scale independently of an application window.
- [Rafael Bessa / BUCK Gemini storyboards](https://www.rafaelbessa.com/works/gemini):
  published design-to-motion sequences show responsive containers carrying the
  idea across states. For CLIO, the prompt grows around inserted contributions;
  its old content is stable rather than dissolved into an unrelated preset.

The repeated product-film grammar is action, consequence, recognition: isolate
the meaningful control; show its action before the changed state; preserve an
object or spatial anchor through the transition; then allow a readable settle.
This is our analysis of the references, not a claim that every brand uses one
template. Shot continuity and causality matter more than adding ornamental motion.

## Visual grammar

White background. Large navy type. Teal for genetics, amber for manufacturing,
lavender for research, blue for simulation. The color follows its capability
through selection and instruction changes. One dominant object per beat.

Classic backspace and retype opens the film. The ad then uses masked letter
reveals, overshoot-controlled springs, scale transitions, rotating capability
tiles and continuous object handoffs. Layouts exist to create those transformations,
not to hold explanatory slides. UI vocabulary supplies the small capability
controls; there is no application window, navigation rail, tab system or pinned
two-column layout. Keep the meaningful prompt change readable after its motion.

The opening and closing are advertising. The middle is a pseudo demo using real
CLIO vocabulary: its agent card, Add plugin control, box/removal icons, expanded
prompt fragments, Skills and MCP servers rows. Reshape and enlarge them for the
film. There is no application shell to navigate. The system prompt grows into a
substantial multi-section document. Each addition has a concrete named piece and
visible textual effect; the existing instructions never get rewritten.

## Approximately thirty-second story

1. Two colored field words type/backspace, then a horizontal wheel accelerates
   through research, climate, robotics, chemistry, energy, astronomy, medicine,
   engineering and more. Increasing blur resolves to a sharp composable.
2. CLIO enters beside the phrase. The highlight contracts into the plus control.
3. The plus unfolds twelve plugin choices around an isolated CLIO agent card.
   Manufacturing docks as the same piece above its prompt contribution.
4. Simulation joins Manufacturing. An additional fragment opens without deleting
   the existing instructions or selected plugins.
5. Parameter sweep arrives in Skills; Materials database arrives in MCP servers;
   Reports joins the plugins. Each addition extends the same prompt. This build,
   rather than a succession of identity rewrites, is the demonstration.
6. The composition resolves to Build your own / CLIO, website and stationary QR.

The soundtrack, if included, is original procedural sound design generated from
the same cue table. Technical checks establish deterministic motion and legible
geometry; creative acceptance still requires judging the encoded moving cut.
