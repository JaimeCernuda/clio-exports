# Historical session scripts

These are byte-preserved one-off scripts and player sources from the October
27–28, 2026 authoring session. `MANIFEST.json` records their original identities.
The maintained renderer, replay, controls, capture, cursor, conformance and
assembly scripts are in `motion/scripts/`, `motion/native/` and `tools/`.

Do not use these historical files as regeneration commands. Some contain paths
from the original machine, write earlier campaign manifests, or encode manually
authored review statements and old test counts. Replaying them can replace newer
work or produce misleading reports. They are retained to preserve all scripts,
not as supported entrypoints. No rendered movies or review images are included.

Start with `.agents/skills/clio-videos/SKILL.md`, `motion/native/README.md` and
`motion/story/README.md`. Use the maintained review CLIs for new measurements;
write a new creative assessment from the actual output and user feedback.
