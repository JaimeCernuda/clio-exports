# Product film, not a session walkthrough

CLIO is the subject. Examples demonstrate its capabilities; they do not become
the film's topic. Rebuild recognizable product UI as editable React/DOM/SVG layers
that can reflow, separate, scale and transform for a shot. Real transcripts constrain
actions, claims and results. The composition controls their presentation. Real
footage may support this reconstruction.

The original 25-second concept proved motion-rendering capability, not successful
art direction. The later Tahoe screenshot cut was rejected. Neither is an approved
visual template. Encoding tests are not creative acceptance.

## First component proof

A single 15-second continuous shot explores one product capability: parallel
delegation while retaining an inspectable parent/child conversation relationship.
It uses the actual reading-guide session, ten real child identities, recorded
file reads and recorded responses. It is deliberately a motion component test,
not the final promo or a claim about run quality or completeness.

| Beat | Motion | Product purpose |
| --- | --- | --- |
| 0–2.7 s | Editable composer types a real request and becomes a conversation message | Start in ordinary language |
| 2.7–6 s | Parent conversation reflows while ten independent agent cards enter | Show delegation as part of CLIO |
| 6–9.3 s | Cards give way to an enlarged child conversation with actual file reads | Inspect the work rather than accept a black box |
| 9.3–15 s | Parent response returns beside the child context, then holds | Keep the result connected to its contributing work |

All timing is editorial. The original run took much longer. No running clock,
performance claim, invented parallel agent, or fabricated scientific result is
introduced. A source-linked excerpt may be deliberately shortened in the shot.

## Future sessions

The collection will grow and may include runs lasting 72 hours. Preserve original
exports, build indexes offline, select source-linked beats, then render only those
small selections. Preserve parent/child identities, source hashes, tool-call IDs,
message/part IDs and excerpt truncation flags. A 72-hour run has not yet been
provided or qualified by this prototype.

## Creative acceptance

The next judgment is whether the moving reconstructed interface makes CLIO
recognizable, understandable and worth exploring. Typography, hierarchy, rhythm,
camera and transformation need visual review. A passing test suite establishes
source/engineering properties only. Expand the film after the component treatment
has useful visual feedback.
