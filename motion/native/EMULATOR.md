# Shared CLIO UI replay emulator

This runtime reconstructs recorded CLIO activity using pinned production React
components. Text, tool rows, A2UI, tabs, panels and pointer paths stay editable.
It reads exported events and saved assets; it does not execute archived tools,
rerun cluster jobs or infer missing scientific results. Start with the
[video catalog](../../videos/README.md) for the relevant story and its review status.

## Runtime choices

| Mode | UI source pin | Port | Data/control path |
| --- | --- | --- | --- |
| Generic transcript and NDP films | `source.json` (`2692126d…`) | 3357 | Native archived rich blocks, snapshots and authored source replay |
| OPAL/SPOTTER film | `source-opal.json` (`f333d67d…`) | 3359 | Main/reviewer pair on one clock; finite captured attention sidecar |
| Wordle study | Same f333d67d pin | 3361 | Scientific events, delegated logs, flow, graph and study-view adapters |
| Engineering film | Same f333d67d pin | 3365 | Native mesh/table reports, captured execution, authored controls |
| Manual attention exploration | Same f333d67d pin | 4394 + backend 18825 | Full native app; new selections computed against local captures/tokenizer |

Use [MANUAL-ATTENTION.md](MANUAL-ATTENTION.md) for the last row. A finite film
response sidecar cannot explain an arbitrary new selection. Manual replay loads
the saved transcript; film replay supplies animated progression and synchronized
editing. Neither launches fresh model inference.

## Common setup

Keep this checkout and generated work on D: on the current Windows machine.
The render/launch tools keep temporary files on the project drive. In a terminal
at the repository root:

```powershell
$repo = (Resolve-Path .).Path
$env:TEMP = Join-Path $repo 'motion/.native-ui/tmp'
$env:TMP = $env:TEMP
$env:TMPDIR = $env:TEMP
New-Item -ItemType Directory -Force -Path $env:TEMP | Out-Null
uv sync --frozen
npm --prefix motion ci
```

Use a **separate clean UI checkout** at the profile's exact revision; do not reset
an active development checkout. For f333d67d, if no suitable checkout exists:

```powershell
git clone https://github.com/iowarp/gact-tui.git motion/.native-ui/source-ui-f333d67d
git -C motion/.native-ui/source-ui-f333d67d checkout f333d67d490174d2f2b82d7c0671e08ee0943ceb
pnpm --dir motion/.native-ui/source-ui-f333d67d install --frozen-lockfile --ignore-scripts
```

For NDP use the revision in `source.json` in another checkout. `run.mjs` verifies
the commit and absence of tracked edits before build/check. The Vite adapters add
recorded-state control ports without editing upstream tracked files. Dependencies
must be installed once; the film runtime itself uses recorded local assets.

## Apply the emulator to a new transcript

```powershell
uv run python tools/prepare_native_scene.py '<export.html>' --out motion/native/public/new-session.native.json --catalog motion/native/public/scenes.json
node motion/native/run.mjs check --source '<clean-default-ui-checkout>'
node motion/native/run.mjs build --source '<clean-default-ui-checkout>'
node motion/native/run.mjs preview --source '<clean-default-ui-checkout>'
```

Open `http://127.0.0.1:3357/?scene=new-session.native.json`. Use exact session,
child, message and part identities when selecting a turn. Keep the export's
`transcript_views`, ordered blocks and `snapshot`; text excerpts alone lose rich
views and tool lifecycle semantics. Asset bytes must exist for every shown view.

Next author source selection, copy, timing and inspections separately. See
[REPLAY.md](REPLAY.md) for ordinary conversation and
[OPAL.md](OPAL.md), [WORDLE.md](WORDLE.md), [ENGINEERING.md](ENGINEERING.md) for
their additional adapters. A new transcript can reuse the renderer; its narrative,
case-specific interaction recipe and uncaptured outputs are not autogenerated truth.

## Code map

| Layer | Implementation |
| --- | --- |
| Native providers, shell and archived views | `workspace.tsx`, `recorded-context-bar.tsx`, `recorded-workbench.tsx` |
| Ordered conversation, disclosure, text and scrolling | `conversation-replay.tsx`, `replay-plan.ts`, `replay-layout.ts`, `replay-markdown.ts` |
| Source timing and concurrent conversations | `paired-replay.ts`, `spotter-replay.tsx`, `study-replay-model.ts` |
| Exact native attention transport and inspection | `paired-attention-transport.ts`, `attention-inspection.tsx`, `manual.vite.config.mjs` |
| Editable controls and pointer | `replay-interaction.ts`, `cursor-plan.ts`, campaign-specific measured tracks |
| Frame-to-paint acknowledgement | `film-plan.ts`, `src/NativeProductFilm.tsx`, independent Wordle/engineering entries |
| Reproducible source import | Repository `tools/prepare_*` scripts and source ledgers |

The iframe acknowledgement waits for the requested native data, fonts and view
state before a frame is captured. A scientific view is not ready merely because
an empty canvas or SVG exists. Measure actual positive-sized view hosts rather
than zero-sized protocol wrappers. Re-measure layout and pointer after changing
source selection, timing or geometry; stale tracks are errors.

## Checks and storage

Run Python pytest/Ruff/pyright and the motion unit/type/format checks. Run the
profile's native check/build, then its browser or moving-proof checks. The
engineering browser test exercises genuine WebGL loss/recovery and direct versus
sequential view sizing. Review encoded joins, selections, loading, scrolling and
captions; automated checks do not approve taste or pacing.

`motion/.native-ui/`, `motion/out/`, `motion/review/`, dependency directories and
large runtime captures stay local. Source packaging includes the emulator,
campaign guides, skills, scripts and small fixtures through
`motion/package-manifest.json`. Full source ZIPs/attention bundles/tokenizer assets
and rendered movies must be supplied separately. Keep original exports unchanged.
