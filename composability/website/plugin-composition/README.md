# Build through plugins

A compact, editable UI composition: add Manufacturing, Simulation and Reports;
remove Simulation and Manufacturing; add Genomics while retaining Reports.
Each click changes the owned instructions and capability branches. No ad branding
or closing call to action is included.

- Edit framing in `Scene.tsx` and the selected source-clock window in `plan.ts`.
- Rebuild from the parent folder: `npm run render -- plugin-composition`.
- Finished files: `output/loop.gif`, `loop.webm`, `loop.mp4`, `poster.png` and manifest.
- The final Genomics state holds before a brief soft reset to the base agent.

This reshapes the shared editable components; it is not a crop of the ad movie.
Use the full-width video where possible so the prompt and capability rows are legible.
