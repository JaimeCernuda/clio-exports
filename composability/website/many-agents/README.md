# Many agents

Steady, seamless vertical rotation through twelve domain words. “A” and “agent”
remain fixed; the logo and ad bookends are omitted.

- Edit text/cadence in `plan.ts` and presentation in `Scene.tsx`.
- Rebuild from the parent folder: `npm run render -- many-agents`.
- Finished files: `output/loop.gif`, `loop.webm`, `loop.mp4`, `poster.png` and manifest.
- The last roll continues directly into the first word. No fade or hard reset.

Use beside a heading such as “So many agents.” See `embed.html` for placement.
