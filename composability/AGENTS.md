# Composability campaign

- Keep advertisement and website materials in their respective folders.
- Website loops have no brand bookend, QR or URL overlay. They are independent
  content for a site that already carries CLIO branding.
- Keep per-asset scenes, timing and finished outputs together. Use shared editable
  UI components rather than cropping the encoded advertisement.
- Review loop joins and real additions/removals. A small website asset still needs
  readable changes and causal gestures.
- Keep generated work, temporary files and dependencies on D: on this machine.
- Keep full ad movies local. Compact website GIF/WebM/MP4/poster files may be
  committed under `website/*/output/` as requested.
- Direct pushes to main remain authorized. Use conventional commits without
  agent attribution.
