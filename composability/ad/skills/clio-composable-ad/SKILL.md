# CLIO composability advertisement

Read [the handoff](../../HANDOFF.md) for the user's ideas, settled choices and
rejected treatments; [art direction](../../ART-DIRECTION.md) for the argument;
and [README](../../README.md) for exact commands and source locations.

Make the viewer understand “build the agent you need.” Show both plugins extending
an existing agent and specialization across many fields. The bookends are PR;
the middle reshapes recognizable CLIO elements for motion. Keep the real owl,
uniform prompt text and matching domain identity. Avoid reconstructing a whole
app, technical catalogue or slide layout. V13 is a baseline, not an approved final.

Choose one opening mechanism. The current decision is a vertical wheel with the
surrounding words fixed; do not mix it with typing/backspacing. Shorten successive
change intervals along a smooth curve. Derive directional blur from cadence and
actual movement: early words readable, late movement blurred, settled words sharp.
The current hook resolves in four seconds. Its front-loaded 48-to-8-frame ramp
must already move quickly by Materials/Chemistry. Do not spend ten seconds on
keyword changes before showing composition.
Use the shared wheel clock for visual and sound cues. Keep the brand,
phrase and plus on one measured center line. Core, filesystem and case-specific
names from other demo campaigns do not serve this concept.

The unit of composition is a plugin. It can own multiple instruction fragments,
skills, MCP servers, tools and hooks. Show these within their owner. A workflow
addition extends the current identity; a domain replacement changes it. Retain
a reusable contribution across domain switches to make reuse visible.

For prompt changes, match ordered words within their source fragment. Preserve
stable text, clear removed text before retained text crosses it, open insertion
space, and reveal the incoming text. Do not crossfade two readable paragraphs in
the same place or reduce the prompt to decorative three-line copy.

Keep the prompt at one fixed scale, position and rectangle through composition.
Do not repeat a small-prompt/large-prompt inspection loop. The persistent tree
connects the prompt to plugins and their owned skills, hooks, tools and MCPs.
Animate leaf names entering and leaving, not just the identity text. Remove count
summary lines and middle-dot separators. Color actual changed prompt fragments
with the owning plugin's tint; leave stable instructions unmarked.

Plan motion through occupied space. Menu-row extraction must preserve the source
rectangle and label on the selection frame. Retire neighbors before growing the
row. Later additions use a persistent global plus above the plugin tree: open
the chooser, select a plugin, dismiss the menu, then insert its row and extend
the prompt. Do not offer an unselected plugin with its own plus. Keep installed
choices visible but disabled. Use the same clock for menu, cursor, insertion and
audio; measure both clicks. Confirm with a check and reveal X after the cursor
leaves; rotating plus into X underneath it reads as a removal click. Show the
first actual removal by clicking its existing X before its owned text/leaves
withdraw. Measure control identity and cursor hotspot at each click, as well as
both sides of the handoff. A filmed cursor
does not trigger CSS hover; derive feedback from the same cues as pointer/audio.
Keep the pointer route continuous between gestures. If it should leave the scene,
move it past the frame edge instead of dissolving it over the work. Include entry
and exit legs when measuring speed, not only the approach to each click.

Unmount hidden contribution text and clip/contain its paint. Keep persistent
subtrees connected; a retained plugin and its leaves move together. Whole nodes
must clear the fixed prompt and other branches. Check the traveling brand against
the prompt at low opacity too: the owl previously crossed the document as it
faded in and out. Delay prompt entrance or logo travel until their paths are clear.
Allow reading time after the last row is fully visible, rather than counting its
fade-in as a hold. Avoid repeating an expanded inspection for every domain.
In the final montage, budget settled time after the prompt morph as well as after
the last capability leaf. A 90-frame morph in a 96-frame interval leaves only
0.1 seconds of settled prompt, despite clean geometry. Keep these brief beats
distinct from time needed to read an entire document.

Every pixel follows the frame. Render fonts and actual DOM measurements first.
Run tests, typecheck, formatting, geometry review, then inspect the encode around
all entrances, edits and exits. The encoded paint audit checks all workers but
does not judge aesthetic quality or every interior pixel. Keep frame inspection,
uninterrupted playback/listening, and user creative approval distinct.

See [review history](../../docs/reviews/) before claiming a prior defect fixed.
Keep the final QR stationary and decodable. The current close uses a larger URL
and QR with no link arrow; preserve that request when changing its layout.
Keep all generated work on the project
volume (D: on the user's machine), source and lessons in Git, and movies local.
