## Three-step reconstruction on RC1 (v3)

Read `videos/spotter-opal/v3/README.md`, its plan and actual review receipt.
The selected source rounds 1/2/5 are displayed as Step 1/2/3. A request may
explicitly authorize reflowing precomputed prompt packets into tool presentations;
that does not authorize claiming new executions. Keep `reconstruction:*` IDs,
exact source spans and a concise reconstruction disclosure. Never write those
views into Flowcept as genuine primary-agent telemetry.

- Stage prompt → three tools → recorded thinking → response. Evidence arrives
  with each tool result, not when Enter submits the request. A step selector gains
  only started steps. Stable dashed step groups grow instead of being replaced.
- Keep Lineage visible while the next container and its result nodes arrive.
  Opening an already complete graph does not demonstrate that progression.
- Tool names alone may be ambiguous: distinguish panel membership from dose
  series even though both use `design_lookup`. Edges start at actual visible
  answers/results and route outside other cards.
- Moving recorded attention to another presentation requires exact token
  ownership and full captured mass. Top-10% display runs cannot allocate the
  rest by character length. Verify capture SHA/bytes, tokenizer round trips,
  disjoint source spans, unchanged residual and total denominator. Ambiguous
  boundary tokens stay in their original domain. Relabelled mass is a source
  grouping in the reconstruction, not a new tool-role inference measurement.
- Retain Words/Max, the global heat scale and a matching conversation rail.
  Never rescale each packet separately to force the override to look hotter.
- Native ring spinners may use `motion-safe:animate-spin`, not `.animate-spin`.
  Drive the actual `data-slot="ring-spinner"` transform from the frame clock.
- DOM-target caches can make direct seeks disagree with sequential capture.
  Measure immutable pointer profiles; test cold/backward seeks against warmed
  frames. Use short deliberate travel and edge exits during long idle intervals.
- Fixed travel durations can still cause speed spikes across a large viewport.
  Budget time from distance and the easing curve's peak velocity; retain measured
  action times. Audit the complete path, including off-frame exits after the
  second selection, and verify the actual DOM pointer pose on every captured frame.
- A native reduced-motion rule of **1ms is still a wall-clock transition**.
  A local cursor stylesheet did not override it. The body portal therefore sets
  transition/animation to `none` with inline priority. Frame-owned descendants
  also need explicit zero durations with sufficient selector priority.
  Require the measured pointer box to agree with its declared frame pose before
  acknowledgement, not merely the correct parent `data-frame`. Persist audit
  poses before evaluating them so a rejected render retains its diagnostic data.
- Reconcile follow-scroll against the settled content extent, rather than a
  height measured before a result finishes opening. A two-frame scroll jump in
  the first conform exposed this. Include its exact source frames in cold/warm
  pixel parity. Sparse renders need discarded source-frame lead-in before every
  discontinuous window; leading handles included in the encode are not pre-roll.
- Keep changing spinner variables on the spinner nodes, not the transcript root.
  Root inheritance invalidated the growing heat DOM every frame. Memoize
  unchanged heat projections; refresh rail geometry when content extent, record
  or aggregation view changes. Preserve its globally scaled values.
- Corrections must cover every affected movement, not just the first failure.
  Derive their union from the immutable path, retain settling handles, test exact
  discontinuous frame replacement, and inspect the assembled movie and its joins.
- Force CFR and a suitable MP4 track time base after concat/framesync. A correct
  frame count did not guarantee `avg_frame_rate=60/1` or a full final-frame duration.
  Qualify decoded count, rate and duration together; preserve the previous final
  until the replacement passes.
- A media player can keep a Windows file open after playback. Close aborted HTTP
  video streams on response close, retry transient promotion locks, and retain
  the verified conform for a finalization-only recovery. A failed rename does
  not justify recapturing an already complete, qualified body.
- Keep recorded reasoning excerpts as source spans. Stream them, hold briefly,
  then animate the disclosure closed. Do not invent private reasoning or leave
  the reviewer frozen while the source clock advances.
- A direct native-page capture can share the Remotion frame/paint protocol. Keep
  whole-shell geometry checks; screenshot pixels must follow acknowledgement.
  Independent pages require exact cold/sequential pixel-parity qualification
  before using them for capture. The historical v2 single-worker rule remains
  applicable to v2; it does not establish parity for a new renderer.
- Reuse the current native selection-action toolbar, including its registry and

- Attention inspection includes the return: scroll back to the answer before
  closing the banner and reopened tool body. Check the complete moving interval,

## The pointer must survive the whole interaction

- Track visibility, position and ownership across setup, menu, selection,
  attention banner, scrolling, return and the next selection. A continuous
  coordinate function does not prove that a visible pointer was encoded.
- One pointer owner should cover the complete interaction. Handoffs between
  independently mounted setup and inspection pointers need explicit review;
  avoid both missing frames and duplicate pointers.
- Inspect clipping, transformed ancestors, stacking contexts, portal roots and
  iframe boundaries. A large local `z-index` cannot cross an ancestor's stacking
  context or escape an iframe. The v1 pointer's `zIndex: 100` was an
  implementation detail, not proof that it stays above native UI overlays.
- Measure targets in the same coordinate space in which the pointer is painted.
  Recheck after reflow, banner arrival, drawer expansion and scrolling. Keep the
  pointer decorative (`pointer-events: none`) so real controls receive input.
- Check the encoded pointer over menus and banners and during drags, not just its
  first and last positions. A single reviewed selection boundary did not qualify
  the complete 4:33 film; disappearance and occlusion remain open.

## Review and publication

Encoding, tests, sampled contact sheets and source ordering did not establish
full-film motion quality. Record what was actually inspected, preserve later
user findings, and keep technical verification separate from creative acceptance.
The review receipt now records the unresolved user-reported defects. A future
revision needs playback of both panes and the pointer across the entire edit,
with full-size adjacent frames around every questionable hold or overlay.

When asked to preserve this work, push scripts, reusable components, selected
source data, manifests, skills and honest review notes to the existing
`clio-exports` branch. Do not render another film or push movie files by default.
Sparse correction renders also need state continuity beyond pointer coordinates.
The v2 join pass found an approval-button focus outline changing and a code block
temporarily blank on the first seeked frame. Include leading handles, discard
their unsettled frames, and verify every defect frame remains covered. Preserve
an unchanged native control from its original frame when it depends on prior
focus events. Inspect each join independently: a single FFmpeg select expression
deduplicates overlapping frame windows and can mislabel a contact sheet's rows.
The local review URL is reused when an encode is replaced. Serve the gallery and
movie ranges with `Cache-Control: no-store`, and test a second range request after
replacing its bytes. A working player can otherwise be reviewing an older file.
